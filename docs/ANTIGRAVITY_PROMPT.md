# Prompt for Antigravity

Build/refine this project as **Spend Smart — Personal Expense Tracking and Analysis System**.

Tech stack: Python, Flask, MySQL, HTML/CSS, Chart.js. Keep the existing lively professional design (navy, purple, pink, mint, cream, rounded cards, responsive layout).

Requirements:
1. Dashboard: total expenses, number of entries, average expense, recent expenses and category-wise chart.
2. Expense form: amount, category, date and optional description.
3. Save records in MySQL and show them in the expense history.
4. Allow deletion of an expense.
5. Validate form inputs and display helpful errors.
6. Test empty dashboard, adding, viewing and deleting records.
7. Read all existing files before modifying them; preserve the stack and explain significant changes.
8. Never hard-code database passwords; use `.env` based on `.env.example`.
9. Do not pretend sample/mockup data is live data.
10. Give clear setup/run instructions and a list of changes.
